# Smart Email Spam & Phishing Risk Classifier

## Project overview

Smart Email Classifier is an educational machine-learning web application that analyzes email text and predicts whether a message resembles a legitimate email or a spam/phishing message. It combines a FastAPI service with a text-classification model and an automated DevSecMLOps workflow.

**Important limitation:** The included model is trained on a tiny, hand-written demonstration dataset. Its predictions and confidence scores are not suitable for real-world security decisions. A larger, properly labelled dataset and rigorous evaluation are needed before practical use.

## Objectives

- Build a small web application and REST API with Python and FastAPI.
- Train a text classifier with TF-IDF and Multinomial Naive Bayes.
- Validate user input and test API behavior.
- Run automated source-code and dependency security checks.
- Use GitHub Actions for continuous integration.
- Package the app in a Docker container.

## Technologies

- Python 3.12
- FastAPI and Uvicorn
- Scikit-learn and Joblib
- Pytest and HTTPX
- Bandit and pip-audit
- Docker
- GitHub Actions

## How it works

1. The user enters email text in the web interface.
2. FastAPI validates the message length.
3. The TF-IDF and Naive Bayes pipeline predicts a category.
4. The app returns the prediction and model confidence estimate.
5. GitHub Actions runs tests, scans Python code and dependencies, and builds the Docker image when code is pushed or a pull request is opened.

## DevSecMLOps components

### Dev — Development

A browser interface and FastAPI endpoints provide the email classification functionality.

### Sec — Security

The API validates input length. Bandit scans Python source code, and pip-audit checks installed dependencies for known vulnerabilities. These tools help identify issues but do not guarantee that the application is secure.

### ML — Machine learning

The application uses TF-IDF to represent email text and Multinomial Naive Bayes to classify it. The included dataset is only for demonstrating the workflow; model quality has not been established.

### Ops — Operations

GitHub Actions automates tests and security checks. Docker packages the application into a container. The `/health` endpoint provides a basic health status.

## Run locally (optional)

Python 3.12 is recommended.

```bash
python -m venv .venv
```

Activate the environment, then install dependencies:

```bash
python -m pip install -r requirements.txt
```

Train the demonstration model:

```bash
python -m app.train
```

Start the app:

```bash
python -m uvicorn app.main:app --reload
```

Open `http://127.0.0.1:8000` for the interface or `http://127.0.0.1:8000/docs` for interactive API documentation.

## Tests and security checks

```bash
python -m pytest -v
python -m bandit -r app tests
python -m pip_audit
```

A security audit may return a non-zero exit code if it identifies vulnerable dependencies. Review and update affected packages rather than ignoring the finding.

## Docker

```bash
docker build -t smart-email-classifier .
docker run --rm -p 8000:8000 smart-email-classifier
```

Then open `http://127.0.0.1:8000`.

## API endpoints

| Method | Endpoint | Description |
|---|---|---|
| GET | `/` | Web interface |
| GET | `/health` | Health status |
| POST | `/predict` | Classify email text |

Example request to `POST /predict`:

```json
{
  "text": "Congratulations! Claim your free prize now."
}
```

The response contains a `prediction`, a `confidence` value, and a warning that the result is only a demonstration. Exact results vary with the trained model.
